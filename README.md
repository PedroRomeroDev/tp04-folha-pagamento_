# Sistema de Cadastro de Funcionário
Programa em Java que cadastra um funcionário e calcula o salário líquido.

Alunos: Pedro Romero e Hugo Eduardo

## Funcionalidades
header(): exibe o cabeçalho do sistema.
calcularImposto(): desconta INSS (14%) e IR (27%) do salário bruto.
horaextra(): calcula o valor das horas extras (R$ 5,00/hora).
main(): coleta os dados do usuário e exibe o salário líquido final.

## Como executar
javac App.java && java App
